# Autonomous research scope

Updated: 2026-09-25. The owner requested autonomous progress and follow-up of interesting findings. This file records scope, not a claim that any scientific question is solved.

## Work rules

Use existing authorized CPU computation. Each new confirmatory experiment needs a committed protocol before new outcomes, bounded repetitions, fixed comparisons and stopping criteria, explicit train/evaluation barriers, and a complete outcome archive. Do not upgrade an exploratory finding by reusing the same observations as confirmation. Preserve every failure and invalid attempt. Do not repeatedly rerun a valid failed experiment or weaken thresholds to obtain PASS.

A closed experiment means its predefined question was tested or its design failed. It does not mean the entire underlying mechanism is identified. Record unsupported, inconclusive, infeasible and resource-blocked questions separately from supported claims.

No automatic X publication, release promotion, paid resource provisioning, GPU purchase, secret/permission change, force-push, or deletion of prior results. Repository changes go through reviewable commits/PRs, except protocol registration and this authorization ledger. Final experiment outcomes must be reported even when negative.
